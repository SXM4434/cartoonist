# Layout and composition

Composition decides where the eye goes and in what order. A page can have perfect type and spacing and still be boring.

## One focal point per surface

Each screenful gets exactly one thing that wins. Everything else supports it. If two elements have equal weight (same size, same contrast, same saturation), the reader picks neither.

Visual weight comes from, in rough order of power: size, contrast, color saturation, isolation (surrounding whitespace), density, motion. Increase one, not four.

## Asymmetry over centering

- Centered everything is the safest and dullest choice. Offset the hero text, let an artifact break the column, allow one element to bleed past the container.
- Asymmetry needs a counterweight: a large light mass balances a small dark one. Without a counterweight it reads as a mistake.
- Optical center sits ~5% above geometric center; center things there for isolated compositions (modals, empty states, splash).

## Figure and ground

- Establish a background hierarchy: page surface, raised surface, sunken surface. Use lightness steps and hairline borders rather than shadows if the system calls for flatness.
- Negative space is a material. A section that is 60% empty with one artifact reads as confident; the same content packed into 100% width reads as a spec sheet.

## Pacing the scroll

Treat the page as a sequence of beats: wide, then narrow; dense, then open; light ground, then dark ground. Three sections with identical structure is the signature of generated layout.

Vary at least: column count, content alignment, background weight, and media scale. Do not vary all of them at once in every section — that becomes noise.

## Review pass

- Blur the screenshot heavily. The focal path should still be readable as a few dark masses in an intentional order.
- Scroll fast. Do the section transitions feel like different rooms, or one corridor?
- Cover the copy. Does the layout alone communicate what kind of thing this is?
