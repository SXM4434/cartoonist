# Breaking the rules

A system that is never broken reads as machine-made. A system broken everywhere reads as broken. The break is the design; the system exists to make it legible.

## The three conditions

A deviation earns its place only if all three hold:

1. **The system is established first.** You cannot break a grid the reader has not yet perceived. Set 2–3 sections of discipline before the break.
2. **It is unmistakably intentional.** Off by 40px reads as a choice; off by 3px reads as a bug. Half-measures are the enemy.
3. **It is rare.** One signature break per page, maybe two. The second break must be a different kind from the first.

## What to break, and how

**Grid.** Let one element bleed past the container edge or straddle two columns. Best for the hero artifact or a single pull-quote. Keep text on the grid even when media leaves it.

**Type ladder.** One off-ladder size, enormous, once — a number, a single word, a headline set at 3× the next step. Never a second one on the same page.

**Spacing scale.** Collapse the gap to zero to weld two elements into one object, or blow it out to 2–3× a section gap to create a held breath before a payoff. Both read as authored; a 1.4× deviation reads as sloppiness.

**Alignment.** Rotate or offset a single decorative artifact (a stamp, a sticky note, a margin annotation) clearly off-axis — 2–6° or 30px+. Never rotate body text or interactive controls.

**Symmetry.** Break a repeating card grid by making one cell double-width or by dropping one cell entirely, using the hole as negative space.

**Color.** Reserve the loudest accent for exactly one element per screen. The break is scarcity, not intensity.

## Never break

Legibility (measure, contrast, minimum sizes), hit targets, focus visibility, reading order, reduced-motion, and the meaning of a semantic color. Expressive risk lives in composition, not accessibility.

## Reviewing a break

Ask: could a careful reader mistake this for an error? If yes, either commit harder or revert. Then ask: if I remove this break, does the page get worse? If it doesn't, it was decoration.
