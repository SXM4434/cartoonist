# Homepage craft

A homepage answers three questions in the first screen: what is this, who is it for, why should I believe it. Everything below the fold earns attention it did not start with.

## The hero is a thesis, not a banner

- One primary claim. Written in the product's own vocabulary, not category language ("meeting canvas" beats "AI-powered collaboration platform").
- Show the actual thing. A real artifact, a live demo, a real screenshot beats an illustration of the idea. If the product produces output, put the output in the hero.
- One primary action. A second action is allowed only if it is materially different in commitment (start vs. see an example). Never two buttons of equal weight.
- Kill the eyebrow unless it carries information the headline cannot (category, availability, launch date). "Introducing" and one-word abstract labels are noise.

## Sequencing

Order sections by the reader's next question, not by feature inventory:

1. What is this (hero)
2. Show me it working (demonstration)
3. Why is it different (mechanism, not adjectives)
4. Why believe you (proof: output, numbers, names, screenshots)
5. What do I get (concrete deliverables)
6. Act (CTA with the friction named — price, signup cost, time)

Break the pattern visually at least twice. If sections 2–5 share one layout template, the page reads as generated. Vary column count, background weight, image scale, and text alignment — but only where the content justifies it.

## Copy rules

- Verbs over nouns. "It hears the weight" over "Advanced audio understanding."
- Specific over superlative. Numbers, names, artifacts. No "seamless", "effortless", "powerful", "revolutionize".
- Section labels describe what happens, not an abstract noun.
- Numbered markers (01/02/03) only when the content is genuinely sequential.

## Cuts

Remove: logo bars without real logos, testimonial cards with invented names, feature grids of 6 identical icon+title+paragraph cells, FAQ sections that answer nothing, a second CTA band that repeats the first verbatim, gradient orb backgrounds.

## Review pass

Screenshot the page at 1280 and 390 wide. Then check:
- Can a stranger say what this does in 5 seconds from the first screen alone?
- Is there one focal point per section, or is every element competing?
- Does any section exist only because homepages usually have one?
- Does the page look like it could belong to a different product with a logo swap? If yes, the hero is not doing its job.
